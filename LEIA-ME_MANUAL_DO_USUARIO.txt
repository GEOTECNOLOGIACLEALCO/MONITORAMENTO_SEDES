================================================================================
           CLEALCO - SISTEMA DE MONITORAMENTO E ROTINA DE VISTORIAS DAS SEDES
================================================================================

Este projeto e uma aplicacao georreferenciada completa (PWA) e sistema de 
gestao de rotina de vistorias tecnicas as sedes rurais da Clealco.

Operacao rapida pelo painel de controle no computador:
👉 MENU_MONITORAMENTO.bat

2. COMO TRANSFERIR ESTE TRABALHO PARA OUTRO COMPUTADOR
================================================================================

Caso precise migrar ou abrir em outra maquina:

1. Basta COPIAR esta pasta inteira ('10_Monitoramento_Sede') para o novo computador
   (ou clonar o repositorio do GitHub):
   git clone https://github.com/GEOTECNOLOGIACLEALCO/MONITORAMENTO_SEDES.git

2. Se a nova maquina precisar rodar os scripts Python de atualizacao de base ou
   download de planilhas, execute uma unica vez no terminal:
   pip install geopandas requests pandas openpyxl

3. Pronto! Basta dar dois cliques em:
   👉 MENU_MONITORAMENTO.bat

4. REGRAS DE TEMATIZACAO POR DATA DA ULTIMA VISTORIA
================================================================================

🟢 Verde:    Ate 7 dias desde a ultima visita (Em dia).
🟡 Amarelo:  De 8 a 15 dias apos a visita (Atencao).
🔴 Vermelho: A partir de 16 dias da visita ou nunca vistoriada (Atrasada / Pendente).
